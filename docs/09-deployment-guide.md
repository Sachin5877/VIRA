# Deployment Guide

## 1. Overview

VIRA is designed as a local web application using open-source technologies. The application can be deployed on Windows, Linux, or macOS without requiring cloud services.

---

## 2. Software Requirements

* Python 3.13+
* Node.js
* npm
* Git
* Ollama
* Llama 3.1 8B Model

---

## 3. Installation Steps

1. Clone the GitHub repository.
2. Install frontend dependencies.
3. Create and activate the Python virtual environment.
4. Install backend dependencies.
5. Install Ollama.
6. Download the Llama 3.1 8B model.
7. Start the FastAPI backend.
8. Start the React frontend.
9. Access VIRA using a web browser.

---

## 4. Future Deployment

The architecture allows future deployment using:

* Docker
* Nginx
* Cloud platforms
* PostgreSQL
* Enterprise authentication systems
