# UI Design

## 1. Overview

The VIRA user interface is designed to provide a clean, modern, and user-friendly experience for security analysts. The interface focuses on simplicity, quick navigation, and effective visualization of cybersecurity alerts and incident response information.

---

## 2. UI Pages

The VIRA platform consists of the following pages:

1. Login Page
2. Dashboard
3. Log Upload
4. Alert Details
5. MITRE ATT&CK Analysis
6. Incident Response
7. Reports
8. Settings

---

## 3. Page Description

### 3.1 Login Page

**Purpose**

Allows users to securely authenticate before accessing the platform.

**Components**

* Username
* Password
* Login Button

---

### 3.2 Dashboard

**Purpose**

Displays an overview of security alerts and system activities.

**Components**

* Navigation Sidebar
* Alert Summary Cards
* Recent Alerts
* Threat Severity Chart
* Recent Reports

---

### 3.3 Log Upload

**Purpose**

Allows users to upload security log files.

**Components**

* File Upload Button
* Supported Formats
* Upload Status
* Processing Status

---

### 3.4 Alert Details

**Purpose**

Displays detailed information about a selected security alert.

**Components**

* Alert Information
* AI Analysis
* Severity Level
* Timestamp

---

### 3.5 MITRE ATT&CK Analysis

**Purpose**

Shows the mapped MITRE ATT&CK tactics and techniques.

**Components**

* Tactic
* Technique
* Technique ID
* Attack Description

---

### 3.6 Incident Response

**Purpose**

Provides AI-generated recommendations for handling detected incidents.

**Components**

* Recommended Actions
* Containment Steps
* Mitigation Suggestions

---

### 3.7 Reports

**Purpose**

Allows users to generate and download incident investigation reports.

**Components**

* Report List
* Generate PDF Button
* Download Report

---

### 3.8 Settings

**Purpose**

Allows users to manage basic application settings.

**Components**

* Change Password
* User Information
* Logout

---
